📜 Грамматика: hay que / se puede

заполни пропуски
Правило:
• Hay que + инфинитив — надо (безлично): Hay que separar el vidrio.
• Se puede + инфинитив — можно: Se puede sacar la basura a las ocho.
• No se puede / Está prohibido — нельзя / запрещено: Está prohibido ensuciar el contenedor.
• График: los lunes y jueves, cada dos días, a partir de las ocho
💡 Впиши конструкцию:
1. ___ separar el papel y el cartón. (надо)
2. ___ sacar la basura a las ocho por la noche. (можно)
3. ___ tirar muebles al contenedor amarillo. (нельзя)
4. Sacamos el orgánico ___ días. (через)
5. Los envases van al contenedor ___. (жёлтый)
6. Sacamos la basura ___ las ocho por la noche. (после / начиная с)

🧩 Грамматика: правила без «ты должен»

таблица + исправь частую ошибку
Фокус урока: «Hay que + инфинитив» — универсальная формула домашних правил; «se puede» — формула разрешения. Справочные строки — для распознавания.
Конструкция Значение Пример
Hay que + инфинитивнадо (безлично)Hay que separar el vidrio.
Se puede + инфинитивможно / разрешеноSe puede reciclar el vidrio.
No se puede + инфинитивнельзяNo se puede ensuciar el contenedor.
Está prohibido + инфинитивзапрещено (официально)Está prohibido tirar muebles aquí.
Hay + сущ.есть, имеетсяHay multa por no reciclar.
💡 Исправь частую ошибку:
1. «Hay separar el vidrio.» ❌ → «Hay ___ separar el vidrio.» (частица обязательна) →
2. «A partir las ocho.» ❌ → «A partir ___ las ocho.» (предлог обязателен) →
3. «Los lunes en jueves.» ❌ → «Los lunes ___ jueves.» (перечисление) →
4. «La recogida cambia el cinco de ___.» (март) →
5. «Sacamos el orgánico ___ días.» (через день) →

📖 Чтение + CLIL: цветовая система контейнеров

прочитай текст и заполни чек-лист

Cinco colores

En los patios españoles hay cinco contenedores. El amarillo es para el envase: botellas de plástico, latas y briks. El contenedor azul es para el papel y el cartón. El contenedor verde es para el vidrio. El contenedor marrón es para el orgánico: restos de comida. Y el resto va al contenedor gris.

El punto limpio

La pila, el aceite y la ropa no van a la basura. Hay un punto limpio en cada barrio y contenedores de ropa en la calle. Está prohibido tirar las pilas al contenedor: hay multa.

El horario municipal

El ayuntamiento fija los horarios de basura. En Valencia el camión pasa a recoger la basura por la noche, a partir de las ocho, y el orgánico se saca cada dos días. La limpieza del patio es tarea de todos: hay que limpiar el envase antes de tirarlo. El residuo que no se recicla va al resto. Descarga la app del ayuntamiento: avisa del día de recogida. Y puedes reutilizar un tarro de vidrio para las especias.

Ответьте на вопросы:
1. ¿Qué va al contenedor amarillo?
2. ¿Dónde van las pilas y la ropa?
3. ¿A qué hora recoge el camión la basura en Valencia?
4. ¿Qué app avisa del día de recogida?

🗣 Говорение: ситуации во дворе

используй шаблоны, произнеси вслух
Ситуация 1: Спросить соседа про картон.
«Perdone, ¿el cartón va al contenedor azul?»
(Извините, картон идёт в синий контейнер?)
Ситуация 2: Объяснить правило семьи.
«Hay que separar el vidrio y el papel.»
(Надо разделять стекло и бумагу.)
Ситуация 3: Спросить про разрешение.
«¿Se puede sacar la basura a las ocho?»
(Можно выносить мусор в восемь?)
Ситуация 4: Рассказать про график.
«Sacamos la basura los lunes y jueves; el orgánico, cada dos días.»
(Мы выносим мусор по понедельникам и четвергам; органику — через день.)
Ситуация 5: Рассказать про исключение.
«Las pilas van al punto limpio. Está prohibido tirarlas a la basura.»
(Батарейки идут в экопункт. Запрещено бросать их в мусор.)
