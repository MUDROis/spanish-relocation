# 🔧 Решение проблемы с распечаткой на Mac

## Что было исправлено

### Проблема
Рабочие листы не распечатывались корректно на Mac из-за жесткой CSS-разметки страниц (`page-break-after: always`, `break-after: page`).

### Решение (два варианта)

#### Вариант 1: Автоматическое распределение при печати ✅
Изменены стили `@media print` для всех файлов:
- Убраны жесткие разрывы страниц (`page-break-after: always` → `page-break-after: auto`)
- Контент теперь течет естественно, браузер сам распределяет задания по страницам
- Сохранена поддержка цветов при печати (`-webkit-print-color-adjust: exact`)

#### Вариант 2: Кнопка сохранения в PDF
Добавлена функция `saveAsPDF()`, которая открывает диалог печати, где можно выбрать "Сохранить как PDF".

## 🎯 Как использовать

### Распечатать на Mac:
1. Откройте файл в браузере (Chrome, Safari, Firefox)
2. Нажмите кнопку **"🖨 Распечатать"**
3. В диалоге печати выберите принтер
4. Печатайте!

### Сохранить в PDF:
1. Откройте файл в браузере
2. Нажмите кнопку **"💾 Сохранить в PDF"**
3. В диалоге печати выберите **"Сохранить как PDF"** в списке принтеров
4. Сохраните файл

## 🛠 Технические изменения

### До (проблема):
```css
@media print{
  .sheet{ page-break-after:always; break-after:page; }
}
```

### После (решение):
```css
@media print{
  .sheet{ page-break-after:auto; break-after:auto; }
  .task, .ex{ break-inside:auto; page-break-inside:auto; }
  @page{ size:A4; margin:10mm; }
}
```

## 💡 Рекомендации для Mac

1. **Safari**: Лучше всего работает с `-webkit-print-color-adjust: exact`
2. **Chrome**: Отлично поддерживает `print-color-adjust: exact`
3. **Firefox**: Используйте оба свойства для совместимости

Если печать всё ещё вызывает проблемы:
- Попробуйте другой браузер
- Убедитесь, что в настройках печати включена опция "Печатать фоновые цвета"
- Сохраните в PDF и распечатайте из Preview
