# Дизайн: перемешивание вариантов в мини-дрилле урока 5.3

Дата: 2026-09-23 · Урок: `lessons/parents/w05-l3.html`

## Цель

В блоке «🎯 Мини-дрилл: выберите правильный перевод» (ШАГ 6) перемешивать порядок вариантов ответов,
чтобы правильный не всегда стоял первым. При каждой отрисовке (первый показ и кнопка «↺ Пройти ещё раз»)
порядок вариантов заново случайный.

## Подход

Вариант A: перемешивание порядка отображения внутри `renderRepetition()`, без изменения данных `repQ`
(`c` остаётся индексом правильного ответа в исходном массиве `o`).

Изменения в `lessons/parents/w05-l3.html`:

1. Добавить функцию `shuffle` (Fisher–Yates, ES5-стиль файла — `var`/`function`), такая же как в остальных
   уроках курса (напр. `w04-l1.html:944`): перед `renderRepetition()`.
2. В `renderRepetition()` (строка ~1086) строить порядок вариантов:
   `var order = shuffle(item.o.map(function(o,oi){ return oi; }));`
   и выводить варианты по этому порядку, записывая в `data-o` ИСХОДНЫЙ индекс вариант
   (`data-o="'+oi+'"`, текст — `item.o[oi]`).
   Сравнение `oi === repQ[qi].c` в обработчике остаётся корректным, т.к. `data-o` теперь хранит исходный индекс.
3. В обработчике клика (строка ~1103) заменить выделение правильного варианта по позиции
   `sibs[repQ[qi].c].classList.add('correct')` на поиск по атрибуту:
   `Array.prototype.slice.call(sibs).find(function(s){ return +s.dataset.o === repQ[qi].c; }).classList.add('correct');`

Не меняются: текст подсказки `'❌ Правильно: '+repQ[qi].o[repQ[qi].c]` (исходные данные), классы
`.correct`/`.wrong`, блокировка `pointerEvents`, вызов `renderRepetition()` в конце и кнопка «Пройти ещё раз».

## Проверка

- `node --check` inline-JS файла (парсинг — ошибок нет).
- Скрипт-проверка: в файле есть `function shuffle(` и вызов `shuffle(` внутри `renderRepetition`;
  строка `sibs[repQ[qi].c].classList.add('correct')` отсутствует, вместо неё — поиск по `dataset.o`.
- Визуально в браузере: правильный вариант в разном положении при перезагрузке/«Пройти ещё раз»;
  неверный клик по-прежнему подсвечивает правильный вариант.

## Не входит в задачу

- Изменение формата `repQ` или введение `data-ok` (вариант C).
- Перемешивание других квизов урока (fillQ уже перемешан).
