# SKILL: mudro-course-builder
Единый скилл для создания контента курса «¡Rumbo a España!» школы МУДРО

## НАЗНАЧЕНИЕ
Один скилл — 4 модуля:
- Модуль 1: Уроки для родителей (50 мин)
- Модуль 2: Уроки для детей (50 мин)
- Модуль 3: Рабочие листы (A4, печать)
- Модуль 4: Совместные уроки и Family Tasks

## КОГДА ПРИМЕНЯТЬ
Активируй, когда пользователь просит создать:
- план урока или HTML-код урока (для родителей ИЛИ детей)
- рабочий лист (worksheet)
- совместный урок или Family Task
- домашнее задание, тренажёр, чекпоинт

## КОНТЕКСТ ПРОЕКТА
- Курс: 20 недель (10 авг 2026 — 4 янв 2027), переезд семьи в Испанию
- Семья: 2 родителя + дети 8 и 12 лет
- Родители: 60 уроков × 50 мин, A1 → A2 Survival, 4 блока
- Дети: 60 уроков × 50 мин, 7 станций
- Платформа: HTML-уроки на GitHub Pages, карточки-перевороты, 🔊 TTS (es-ES), тренажёры

# 🎯 ОБЩЕЕ ЯДРО МЕТОДИКИ (для всех 4 модулей)

## Трёхфазная модель
Каждый урок/лист строится по принципу:
ИЗУЧЕНИЕ (Input) → ЗАКРЕПЛЕНИЕ (Drill) → ПРАКТИКА (Output)

Золотое правило: каждый изученный элемент (слово, конструкция) НЕМЕДЛЕННО
применяется в упражнении. Никакого материала «про запас».

## Формула урока
ТЕМА → ЛЕКСИКА → ГРАММАТИКА → ФОРМАТ → ПРОДУКТ
- ТЕМА: жизненная ситуация (не академическая единица)
- ЛЕКСИКА: 30–40 слов-чанков для взрослых, 10–15 для детей, применимых сразу
- ГРАММАТИКА: 1–2 конструкции В КОНТЕКСТЕ темы (не отдельно)
- ФОРМАТ: типы активности
- ПРОДУКТ: что ученик создаёт (карта, письмо, документ, паспорт)

## 5 навыков — обязательная матрица
Каждый продукт должен включать ВСЕ 5 навыков:
| Навык | Изучение | Закрепление | Практика |
| 📖 Чтение | текст по теме | вопросы | анализ реального документа |
| 👂 Аудирование | аудио-описание | задание на понимание | реакция на речь |
| 🗣 Говорение | повторение | произнесение | ролевая игра / описание |
| ✍️ Письмо | — | пропуски | домашка / рабочий лист |
| 🧩 Грамматика | конструкция в контексте | упражнение | свободное использование |

## Тон и стиль (единый для всех модулей)
- Дружелюбный, живой, вдохновляющий, с фокусом на пользу
- Эмодзи для визуальных акцентов, но без излишнего сленга
- Лаконичные структуры: заголовок, короткие абзацы, списки, таблицы
- Испанский с переводом и транскрипцией при первом упоминании
- Фирменные цвета МУДРО: терракота #E2725B, олива #7A8B4C, шафран #E9A13B, океан #3E7CB1

# 📗 МОДУЛЬ 1: УРОКИ ДЛЯ РОДИТЕЛЕЙ (50 мин)

## Шаблон урока
### Блок 1. ИЗУЧЕНИЕ (15–20 мин)
1. Разминка (3–7 мин): блиц-квиз по прошлому уроку + «мост» к новой теме
2. Лексика (7–10 мин): карточки-перевороты, слово + пример по теме + 🔊
3. Грамматика (8–10 мин): формула + примеры с лексикой урока
4. Аудирование (опц., 3–5 мин): аудио по теме + кликабельные слова

### Блок 2. ЗАКРЕПЛЕНИЕ (15–20 мин)
- Упражнение на лексику (сопоставление / впиши / выбери)
- Упражнение на грамматику (все примеры с лексикой урока)
- Чтение текста + вопросы
- Аудирование + задание

### Блок 3. ПРАКТИКА (10–15 мин)
- Говорение: ролевая игра / конструктор → произнести вслух
- PBL-проект: продукт урока

## Правила лексики (родители)
- 30–40 слов на урок (полный словарный запас недели)
- Каждое слово — в примере по теме урока
- Озвучка: слово на лицевой стороне, пример на обороте
- Прилагательные озвучивай только в базовой форме (муж. род)
- Формат карточки: [слово + перевод + 🔊] / [пример + перевод примера + 🔊]
- Добавляй блок «Ложные друзья переводчика» (barrio ≠ бар, plaza ≠ плаза)
- Распределяй лексику по подразделам: существительные / глаголы / прилагательные / устойчивые выражения

## Правила грамматики (родители)
- Максимум 1–2 конструкции на урок
- Вводи через примеры с лексикой урока
- НЕ давай таблицу спряжения отдельно — формула + примеры по теме
- Озвучивай только конструкцию (без примеров)
- Выделяй правила слияния/исключения (de + el = del, a + el = al)

## Домашка родителей (25–30 мин)
Обязательный состав:
1. 🎤 Говорение (голосовое) — 5–7 мин
2. 🌍 Реальное действие (PBL) — 5–7 мин
3. 📖 Чтение / лексика — 5 мин
4. ✍️ Письмо (сочинение 6–8 предложений) — 5–10 мин
5. 🎮 Тренажёр — 5–10 мин
6. 👨‍👩‍👧 Семейная миссия (если применимо) — 5 мин
Письмо НЕ входит в 50 минут урока — выносится в домашку или рабочий лист.

## Интерактив родителей
- Карточки: переворот (flip) + 🔊 TTS
- Грамматика: формула + примеры + 🔊 только конструкция
- Чек-листы: кнопка 🔊 + текст + перевод + инструкция
- Тренажёр: 3 режима (карточки / сопоставление / собери фразу)
- Проверка: ✅ зелёная галочка при верном, ❌ красный крестик при неверном
- Самопроверка: «Светофор» 🟢🟡🔴 с кликом
- Навигация: ← Предыдущий / ↺ Карта курса / Следующий →
- Блок Quizlet со ссылкой на набор урока

# 📘 МОДУЛЬ 2: УРОКИ ДЛЯ ДЕТЕЙ (50 мин)

## Принципы детского урока
- Игровой подход: все блоки — мини-приключения (паспорт, мяч, карта)
- Мультисенсорность: карточки + озвучка + конструкторы + игры + TPR
- Связь с семьёй: ребёнок становится «учителем» для родителей
- Прогрессия: от простого к сложному, от «я» к «они»
- Геймификация: наклейки-стикеры за станцию, альбом достижений, конфетти
- Самооценка: «Смайлик» 😄/🙂/😅 (НЕ «Светофор»)

## Лексика детей
- 10–15 слов на урок (полный словарный запас недели)
- Каждое слово с жестом/действием (TPR)
- Карточки яркие, с эмодзи
- Озвучка обязательна для каждого слова
- Распределяй по подразделам: существительные / глаголы / прилагательные / фразы

## Структура детского урока (7 блоков)
1. 🗺 Куда мы едем? (5–7 мин) — страна, карта, 3 интересных факта
2. 👋 Приветствия / тема (10 мин) — карточки с озвучкой
3. 🎤 Волшебные фразы (10 мин) — конструктор визитки
4. 🤝 Представляем других / применяем (7 мин)
5. 🔢 Цифры / лексика темы (6 мин) — игра «Поймай число»
6. 📘 PBL-продукт (7 мин) — паспорт, рюкзак, карта, макет
7. 🎾 Игра-викторина (3 мин) — «La Pelota Preguntona» (мяч)

## Продукты детского урока
Всегда материальный артефакт:
- Паспорт испанского школьника 📘
- Рюкзак мечты 📚
- Карта школы / квартиры 🗺️
- Макет класса (Minecraft/бумага) 🎨
- Emoji-дневник настроения 😄
- Семейное дерево 🌳

## Домашка детей
- Задания ТРЕБУЮТ участия родителей (ребёнок = учитель)
- Формат: «Научи родителей…», «Представь родителей друг другу…»
- 5–7 коротких заданий + тренажёр + самопроверка «Смайлик»

## Грамматика детей
- Вводится через «секреты» и «волшебные правила»
- Пример: «Возраст — это сокровище, поэтому tengo 8 años, а не soy 8 años»
- Буквы-герои: LL [й], Ñ 🐌 (улитка), H 👻 (невидимка)
- Спиральная подача алфавита (станция 1 → 2 → 3)

# 📙 МОДУЛЬ 3: РАБОЧИЕ ЛИСТЫ (A4, печать)

## Назначение
Письменное закрепление урока. НЕ дублирует урок, а переносит его на бумагу.

## Формат
- 3–4 страницы A4 + страница ключей
- Кнопка «Распечатать» (position:fixed, скрывается при печати)
- @page size:A4; постраничная разметка .sheet
- Шапка в стиле урока (hero с градиентом, имя/дата)
- Цветные кружки-номера упражнений
- Футер с нумерацией «стр. X / Y»

## Структура листа (порядок = методика)
1. Лексика: сопоставление / впиши по описанию / выбери по контексту
2. Грамматика: вставь / собери / переведи
3. Чтение: текст + вопросы
4. Аудирование: прослушай + ответь (с QR или ссылкой)
5. Говорение: опиши / объясни (Imperativo, маршрут)
6. Письмо: свободное сочинение (7–8 строк)
7. Самопроверка «Светофор»
8. Ключи для преподавателя (отдельная страница)

## Правила рабочих листов
- Светофор: КОМПАКТНЫЕ кружки (6×6 мм) в ОТДЕЛЬНЫХ колонках (span внутри td)
- Ключи: на последней странице, с линией отреза ✂️
- Проверка: ✅ при верном / ❌ при неверном ответе
- Упражнения идут в том же порядке, что и блоки урока
- Все примеры используют лексику текущего урока

# 📕 МОДУЛЬ 4: СОВМЕСТНЫЕ УРОКИ И FAMILY TASKS

## Концепция
Семья — единая обучающаяся система. Успех ребёнка зависит от успеха
родителей и наоборот. Совместные задания — «мосты» между детским
(школьным) и родительским (административным) мирами.

## Family Tasks (20 недель, по 1 на неделю)
Правила:
- Длительность 5–15 минут
- Интегрируется в повседневную рутину (ужин, прогулка)
- НЕ требует повторения одного материала
- Каждый использует СВОИ уникальные знания для общей цели
- Ребёнок описывает предметы/чувства, родитель объясняет ситуации
- Результат — настоящий диалог, а не монолог
- Формат: печатный шаблон / скриншот / фото / голосовое

Примеры Family Tasks:
| Неделя | Тема | Детский вклад | Родительский вклад |
| 1 | Семейный паспорт | имя, возраст, страна | профессия, опыт |
| 2 | Моя комната / Наша квартира | рисунок комнаты | объявление Idealista |
| 4 | Семейная аптечка | рисунок аптечки | поиск лекарств |
| 6 | Маршрут до школы | маршрут Google Maps | представление соседу |

## Совместные уроки (7 штук, 90–180 мин)
Правила:
- Проводятся после завершения ключевых блоков
- Формат: квест или ролевая игра «реального времени»
- Концентрируются на «высокорисковых» сферах (школа, здоровье, жильё)
- Участники — активные агенты, а не наблюдатели
- Продукт — семейный артефакт (манифест, конституция, профиль, маршрут)

7 точек синхронизации:
| Урок | Детская станция | Родительский блок | Продукт |
| 9 | Supervivencia | Misión Residencia | Семейный манифест 📜 |
| 21 | Mi Colegio | El Cole y la Salud | Конституция школы 📋 |
| 33 | Mi Mundo | Logística Diaria | Семейный профиль 📷 |
| 42 | CLIL | Logística Diaria | Карта + бюджет 🗺️ |
| 51 | ¡A Comer! | Vida Social | Меню + рынок 🍽️ |
| 57 | Mi Ciudad | Vida Social | Семейный маршрут 🚌 |
| 60 | ¡Preparados! | Vida Social | Выпускной 🎓 |

## Синхронизация модулей
Находи «точки пересечения», где темы детей и родителей — две стороны
одной медали:
- ser/tener: дети «Soy de Rusia» ↔ родители «Tengo una visa»
- школа: дети «¿Dónde está el baño?» ↔ родители «¿Dónde está el centro de salud?»
- еда: дети «la manzana» ↔ родители «Tengo alergia al pan»
- числа: дети считают ↔ родители читают договор аренды

# ✅ ОБЩИЙ ЧЕК-ЛИСТ ПЕРЕД ВЫДАЧЕЙ

## Для любого продукта проверь:
□ Формула: ТЕМА → ЛЕКСИКА → ГРАММАТИКА → ФОРМАТ → ПРОДУКТ
□ Все 5 навыков на месте
□ Трёхфазная модель: изучение → закрепление → практика
□ Лексика в примерах по теме, грамматика в контексте
□ Проверка: ✅ при верном / ❌ при неверном
□ Тон дружелюбный, с эмодзи
□ Есть связь с другими продуктами курса (предыдущий/следующий урок)

## Специфичные чек-листы:
- Родительский урок: разминка-мост, 30–40 слов, PBL-продукт, домашка 6 типов
- Детский урок: игровой подход, 10–15 слов, PBL-артефакт, «Смайлик», связь с родителями
- Рабочий лист: A4, кнопка печати, порядок = урок, ключи с линией отреза
- Совместный продукт: 5–15 мин (Task) или 90–180 мин (урок), семейный артефакт

# 🚫 ЗАПРЕЩЕНО (для всех модулей)
- Грамматика в отрыве от темы
- Больше 40 слов на урок (родители) / 15 слов (дети)
- Материал «про запас» (без немедленного применения)
- Продукт без хотя бы одного из 5 навыков
- Озвучка прилагательных во всех формах (только базовая)
- Письмо внутри 50 минут урока (выносить в домашку/лист)
- «Светофор» в детских уроках (использовать «Смайлик»)
- «Смайлик» в родительских уроках (использовать «Светофор»)
- Сухой академический тон без эмодзи и живости
- Семейные задания, где все повторяют один и тот же материал
