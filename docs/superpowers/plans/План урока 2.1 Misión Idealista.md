## 🧠 ГРАММАТИКА УРОКА

### 1. Busco… — Я ищу… (Presente, правильные глаголы)
```
buscar → busco · buscamos
```
**Пример:** Busco un piso con dos habitaciones. — Я ищу квартиру с двумя комнатами.

### 2. Hay… — Есть / имеется (или нет)
```
Hay dos habitaciones. — Есть две комнаты.
No hay ascensor. — Нет лифта.
```

### 3. Está… — Находится / является (о состоянии)
```
Está en el centro. — Она в центре.
Está amueblado. — Она с мебелью.
```

### Конструктор «Идеальная квартира»
```
Busco un piso en alquiler con {N} habitaciones [en {zona}] [amueblado] [luminoso] por menos de {сумма} euros al mes.
```
