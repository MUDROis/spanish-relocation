🔄 SER vs ESTAR — два «быть»

⏱ 8 минут

Ключевой грамматический блок урока! В испанском есть ДВА слова для «быть».

Метафора для тебя:
🛂 SER — это твой ПАСПОРТ: кто ты есть ВСЕГДА. Soy ruso (я русский), Soy alto (я высокий).
📔 ESTAR — это твой ДНЕВНИК настроения: как ты СЕЙЧАС. Estoy contento (я рад), Estoy cansado (я устал).

Паспорт не меняется каждый день, а настроение — да! Эмоции = всегда ESTAR!

🗓 ВСЕ формы глагола ESTAR (быть — сейчас)

🛂 ВСЕ формы глагола SER (быть — всегда)

Мнемоника:
🔵 SER = DOCTOR — Description (описание), Occupation (профессия), Characteristic (черта), Time (время), Origin (происхождение), Relationship (отношение).
🟢 ESTAR = PLACE — Position (положение), Location (место), Action (действие), Condition (состояние), Emotion (эмоция).
Ещё пример: Soy feliz (я счастливый человек — черта характера) vs Estoy feliz (я счастлив сейчас). Но для простоты в нашем курсе: эмоции = ESTAR!
Добавь причину! «Estoy nervioso porque es mi primer día» — «Я нервничаю, потому что это мой первый день».
