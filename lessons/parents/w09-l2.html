Утром вы описали симптомы и записались к педиатру. Он выписал рецепт. Теперь — аптека через дорогу. Сначала блиц по уроку 9.1 «Симптомы детей».

⚡ Блиц-квиз: урок 9.1

💊
Одна ситуация: ¿Para quién es?
Поликлиника приняла, педиатр выписал рецепт. Аптека — через дорогу, зелёный крест. Отвечайте вслух, нажимайте 🔊.
Вы:
Buenas tardes. ¿Tiene algo para la tos?
Добрый день. Есть что-то от кашля?
Фармацевт:
¿Para quién es? ¿Para usted o para el niño?
Для кого? Для вас или для ребёнка?
Вы:
Para mi hijo, tiene cuatro años.
Для моего сына, ему четыре года.
Фармацевт:
Vale, le recomiendo este jarabe sin azúcar. Una dosis de cinco mililitros cada ocho horas.
Хорошо, советую этот сироп без сахара. Доза — пять миллилитров каждые восемь часов.
Вы:
Perfecto. ¿Cuánto cuesta?
Отлично. Сколько стоит?
Фармацевт:
Con la receta electrónica, cuatro euros. ¿Quiere también tiritas?
С электронным рецептом — четыре евро. Хотите ещё пластырей?

❓ Два вопроса по ситуации

1Для кого лекарство?
Para el hijo, cuatro años.
Para la madre.
Para el padre.
2Что значит «cada ocho horas»?
Каждые 8 часов.
8 раз в день.
Через 8 дней.
🧩 Мост к теме урока: формулы tener + симптом и estar + состояние вы уже знаете. Сегодня добавляем вежливые просьбы (¿Puede...? Me pone...) и язык инструкций (cada 8 horas, con comida, antes de dormir). Фармацевт в Испании — бесплатный мини-консультант, спрашивайте смело.

Карточки со словами: 35 слов об аптеке

Нажмите на карточку — она перевернётся и покажет пример. 🔊 — послушать произношение.

💡 Культурный нюанс: зелёный крест — аптека. Аптеки частные, но лицензированные; по будням открыты примерно 9:30–21:00. Ночью и в выходные всегда дежурит farmacia de guardia — список на двери и на сайте автономии. Антибиотики — только по рецепту; почти всё остальное (para la tos, la fiebre) — свободно.

2

Грамматика: tener, estar и вежливые просьбы

15:00 – 23:00 · Фокус: ¿Puede...? / Me pone...

В аптеке нужны три вещи: назвать симптом (tener), описать состояние (estar) и вежливо попросить (¿Puede...? / Me pone...?).

📐 Tener + симптом (повторение + расширение)

Форма Пример
tiene fiebre / tos / mocos El niño tiene fiebre y mucha tos.
no le baja la fiebre No le baja la fiebre desde ayer. — Температура не спадает со вчера.
tiene alergia a... Tiene alergia a la penicilina. — Важно сказать в аптеке!
¿Tienes sed? / ¿Tiene hambre? ¿Tiene sed? Bebe poca agua.

📐 Estar + состояние (повторение)

Está enfermo / pálido / cansado. — Он болен / бледен / устал.
Está mejor hoy. — Сегодня ему лучше.
Está peor. — Ему хуже. (сильное слово — врач поймёт срочность)
La niña está mejor, gracias. — Девочке уже лучше, спасибо.

📐 Вежливые просьбы в аптеке

Формула Пример
¿Tiene algo para...? ¿Tiene algo para la tos? — Есть что-то от кашля?
¿Qué me recomienda? ¿Qué me recomienda para el niño? — Что посоветуете для ребёнка?
¿Puede darme...? ¿Puede darme dos cajas, por favor? — Дайте две упаковки, пожалуйста.
¿Me pone...? ¿Me pone un termómetro digital? — Дайте (взвесьте) цифровой термометр?
Necesito algo para... Necesito algo para el dolor de cabeza.
para + цель para la tos, para el niño, para dormir — para = для / от
📌 Фокус практики: связка «симптом → кто → просьба»: Es para mi hijo. Tiene tos. ¿Qué me recomienda? — три предложения закрывают 80% визита в аптеку.
⚠️ Частые ошибки:
• «Necesito algo de la tos.» ❌ → «Necesito algo para la tos.» ✅ (para = «от / для»)
• «Me pone dar dos cajas.» ❌ → «¿Me pone dos cajas?» ✅ (после me pone — просто существительное)
• «¿Cuánto es?» — про цену товара; «¿Cuánto es?» — на кассе. Не перепутайте: на кассе чаще всего говорят именно ¿Cuánto es?
• «Cada ocho horas de tiempo.» ❌ → «Cada ocho horas.» ✅ (без лишних слов)

📐 Готовые чанки аптеки

Es para mi hijo, tiene cuatro años. — Для сына, ему четыре года.
El pediatra recetó un jarabe. — Педиатр выписал сироп.
Una dosis cada ocho horas, después de las comidas. — Доза каждые восемь часов, после еды.
¿Tiene algo sin azúcar? — Есть что-то без сахара?
¿Hay farmacia de guardia hoy? — Есть сегодня дежурная аптека?

🧩 Упражнение 1: Вставь слово или форму глагола

Используйте: tiene, para, cada, de, cuesta, está.

Ролевая игра + продукт: диалог с фармацевтом

37:00 – 47:00 · CLIL + конструктор + парная игра

📖 CLIL-мини-текст: как устроены аптеки в Испании

La cruz verde

Аптеки — частные, но работают по государственным ценам на рецептурные лекарства. Одна аптека примерно на 1500 жителей — найти не проблема. Copago (сооплата) зависит от дохода; лекарства для детей до 18 лет обычно бесплатны.

Farmacia de guardia

Каждая зона имеет дежурную аптеку по ночам и выходным. Список — на двери каждой аптеки; в Google Maps ищите «farmacia de guardia hoy». Запишите ближайшую заранее — ночью искать её времени не будет.

El prospecto y la dosis

Листок-вкладыш читайте всегда: dosis, cada X horas, con / sin comida. Для детей фармацевт подбирает форму: jarabe, supositorio, espray. Не уверены — спросите: «¿Puede explicarme la dosis?»

📋 Чек-лист визита в аптеку:
☐ Назвать симптом: ¿Tiene algo para...?
☐ Ответить «¿para quién es?»: возраст ребёнка
☐ Показать SIP / сказать про receta electrónica
☐ Понять инструкцию: dosis, cada X horas, con comida
☐ Спросить цену: ¿Cuánto es?
☐ На будущее: ¿Dónde está la farmacia de guardia?

🎭 Ролевая игра в парах

Разыграйте диалог «родитель ↔ фармацевт». Затем поменяйтесь ролями.

🎭 Роли

👩‍⚕️ Роль A — Фармацевт
  • Встречает: «Buenas tardes, ¿qué necesita?»
  • Уточняет: «¿Para quién es? ¿Cuántos años tiene?»
  • Про рецепт: «¿Tiene receta electrónica?»
  • Даёт инструкцию: «Una dosis cada ocho horas, con comida.»
  • Называет цену: «Son doce euros con el copago.»
👨 Роль B — Родитель
  • Просит: «Necesito algo para la tos.»
  • Объясняет: «Es para mi hijo, tiene cuatro años.»
  • Описывает: «No le baja la fiebre desde ayer.»
  • Спрашивает: «¿Qué me recomienda? ¿Hay algo sin azúcar?»
  • Платит: «¿Cuánto es? Pago con tarjeta.»
🆘 Фразы-спасатели:
• «¿Puede escribirlo en un papel?» — Можете написать на бумаге?
• «¿Este medicamento es para niños?» — Это лекарство для детей?
• «¿Puedo abrir la caja?» — Можно открыть упаковку?
• «¿Tiene algo más barato?» — Есть что-то дешевле?

Домашнее задание · Урок 9.2

🎮 Задание 1. Тренажёр слов и грамматики · 7 мин

Цель: довести до автоматизма 35 слов и формулы просьб.

🎤 Задание 2. Голосовое «En la farmacia» · 6 мин ⭐

Цель: проговорить весь визит в аптеку.

Запишите голосовое на 6–8 реплик по шаблону из конструктора, минимум 2 дубля:

Buenas tardes. ¿Tiene algo para [проблема]? Es para mi hijo/a [имя], tiene [возраст] años.

📍 Задание 3. Реальное действие · 5 мин

Цель: подготовить «карту здоровья» своего района.

Найдите ближайшую аптеку и farmacia de guardia рядом с домом. Запишите:

Farmacia más cercana: ___ (dirección, horario)
Farmacia de guardia de mi zona: ___
Teléfono: ___

✍️ Задание 4. Письмо: диалог в аптеке · 7 мин

Цель: закрепить структуру диалога письменно.

Напишите диалог «фармацевт ↔ родитель» из 8 реплик. Используйте минимум 2 формулы просьбы и 1 инструкцию.

👨‍👩‍👧 Задание 5. Семейная миссия · 3 мин

Цель: связать родительский урок с детским курсом.

Соберите аптечку вместе с ребёнком, называя предметы по-испански:

La tirita — пластырь
La gasa — марля
El termómetro — термометр
El suero oral — раствор для регидратации

Ребёнок повторяет и наклеивает наклейки. Родитель резюмирует:

Vale, el botiquín está listo. Si te caes, tenemos tiritas.

🧰 Задание 6. Мини-проект: «Mi botiquín» · 10–12 мин

Цель: собрать relocation-аптечку с испанскими названиями.

Составьте список из 10 предметов своей семейной аптечки с испанскими названиями (заметка в телефоне или бумага). Отметьте, что уже куплено, а что искать в Испании.
